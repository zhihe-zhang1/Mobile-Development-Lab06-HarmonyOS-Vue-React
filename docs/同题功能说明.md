# 同题异构：统一功能与验收步骤

三个技术栈的共同题目是：**商品列表异步加载、按名称/分类/编号搜索、查看详情和收藏商品**。

在 ArkTS 中，直接使用实验五的原生工程作为已完成的基准方案；Web 示例另行实现相同的关键业务交互。Vue 3 和 React 两个项目采用一致的数据和演示延时，方便比较代码风格。

## 测试数据

| 商品编号 | 名称 | 分类 | 价格（CNY） |
| --- | --- | --- | ---: |
| EL-101 | 无线蓝牙耳机 | 数码 | 129.00 |
| DS-102 | 方格笔记本 | 文具 | 19.90 |
| EL-103 | 折叠桌面支架 | 数码 | 39.90 |
| LT-104 | 随行保温杯 | 日用 | 69.00 |
| DS-105 | 抽绳帆布笔袋 | 文具 | 29.90 |

## Web 验收用例

| 编号 | 操作 | 预期结果 |
| --- | --- | --- |
| T1 | 打开页面 | 先出现 Loading，约 650ms 后列出五件商品 |
| T2 | 搜索“文具” | 仅显示方格笔记本、抽绳帆布笔袋 |
| T3 | 点“空数据” | 显示 Empty 和可操作的恢复按钮 |
| T4 | 点“失败模拟” | 显示 Error 和重试按钮 |
| T5 | 进入 EL-101 详情 | URL hash 进入 `/product/EL-101`，显示价格和说明 |
| T6 | 在详情收藏并返回 | 收藏页签出现 EL-101，商品页不丢失 Tab 选择 |
| T7 | 刷新页面 | 收藏仍保留（浏览器 localStorage） |
| T8 | 连续切换三个加载模式 | 后发请求结果为准，不被前一次请求覆盖 |
| T9 | 直接在地址栏打开 `#/product/NOT-FOUND` | 显示商品不存在，允许返回 |

注：ArkTS 的 Preferences 是本地应用 KV 持久化，Web 的 localStorage 属于浏览器源下的存储，两者不是相同的存储介质。实验不涉及真实账户、密码或 Token。
